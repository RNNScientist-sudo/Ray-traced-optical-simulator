About the Project:
An interactive web application designed to demonstrate the fundamental principles of geometric optics. Built with React, TypeScript, and high-performance HTML5 Canvas rendering, this tool helps physics students, teachers, and STEM enthusiasts visualize light behavior across converging and diverging optical systems.

Key Features:
1. Four Core Optics Modes: Full support for Convex Lenses, Concave Lenses, Concave Mirrors, and Convex Mirrors.
2. Real-Time Ray Tracing: Visual rendering of Parallel, Central/Vertex, and Focal rays alongside virtual image extensions.
3. Cartesian Physics Accuracy: Real-time calculation of image distance, focal length, object distance, and
   magnification, adhering strictly to thin-lens and mirror equations.
5. Interactive Controls: Drag object vectors, shift focal parameters dynamically, and observe immediate line-of-sight updates.
6. Custom Themes: Clean UI toggling between high-contrast dark and light laboratory visual palettes.
7. Zero-Latency Client Engine: Runs entirely client-side in the browser for fluid 60 FPS performance.
